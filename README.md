The Boost physio Clinic (BPC) is a Java based application created to smooth-running the functions of a physiotherapy clinic. The system handles the patient’s records, making appointments and treatment plans. The system aims to minimize errors, avoid double booking. It also provides clear visibility of available treatment times.
BPC is made of command line-based applications. It allows users to register patients, book appointments, reschedule appointments, cancel appointments, attend appointments and produce reports. It uses java’s standard libraries for leading times and data structures. The system works on object-oriented programming concepts. The status of appointments is managed by using Enums ensuring clarity and consistency.
In general, the BPC system provides a well order and systematic way to manage the day-to-day activities of physiotherapy clinics. It is easy to use and reliable. It offers potential for future improvements such as graphical user interface or database connectivity.
